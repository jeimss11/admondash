La fábrica es siempre una ubicación física separada. Esta configuración solo define si la mercancía que sale de fábrica se lleva como una bolsa compartida o como saldo de cada distribuidor. No modifica ni recalcula el stock absoluto que sincroniza la aplicación móvil.

Protección de integración: un móvil puede sincronizar cantidades absolutas. Por eso fábrica, bolsa compartida, distribuidores y conciliaciones se guardan fuera de productos; nunca se interpreta una cantidad ausente como cero.
